# MS Pain — Moving Platforms, Object Swapping and Enemy Behaviour
**Brian Tam · Gameplay programming and testing · University team project**

I helped build gameplay features for MS Pain, a university team game: moving platforms, object-swapping mechanics, rat-enemy behaviour and shortcuts for testing. This page explains my individual contributions. The complete game remains in the private team repository.

## How the work developed
**Goal:** Add moving platforms, object swapping and enemy behaviour to the game, with shortcuts to support gameplay testing.

**Feature development:** The history records an initial swap-item implementation on 28 February, followed by a swap-item bug fix on 5 March. Rat AI work followed on 6 March, patrol updates on 10 March and rat testing on 11 March. Later commits added vertical moving platforms and a cheat-code script.

**Working with team updates:** I used the Brian branch and merged updates from develop and a teammate's branch into it. This let my work continue alongside changes to the shared project.

**Evidence available:** The commit record below supports this development sequence. The exact swap bug, detailed test results and final integration outcome are not established by those titles alone.

# MS Pain — Gameplay Programming
**Brian Tam · C# · University team project**

MS Pain is a team game where players switch between a character and its shadow. My contributions included swap items, enemy patrol work, vertical moving platforms and testing shortcuts.

**[Watch the browser example](https://light1088.github.io/ms-pain-contributions/)** — select **Watch a quick example**. It shows a player using a charge, reaching a pickup and restoring it. The moving platforms demonstrate repeatable movement and timing.

## How my work developed
I started with the **swap item**, then committed a **bug fix**. Next came **rat AI**, followed by **patrol updates and testing**. I later added **vertical moving platforms** and a **cheat-code script**, merging team updates along the way.

The browser demonstration adapts selected C# mechanics to JavaScript using simple shapes. The original PainterEngine team game remains private.

# MS Pain — Gameplay Programming
**Brian Tam · C# · University team project**

MS Pain is a team game where players control a main character and its shadow. A “character switch” means changing which one you control. Taking control of the shadow uses one available switch. Items restore used switches, up to a maximum of four. My contributions included these items, enemy patrol work, vertical moving platforms and testing shortcuts.

**[Watch the browser example](https://light1088.github.io/ms-pain-contributions/)** — select **Watch a quick example**. It shows the number of character switches remaining: 2 → 1 when one is used, then 1 → 2 when the player reaches a gold item and restores it. The moving platforms demonstrate repeatable movement and timing.

## How my work developed
I started with the **item that restores a character switch**, then committed a **bug fix**. Next came **rat AI**, followed by **patrol updates and testing**. I later added **vertical moving platforms** and a **cheat-code script**, merging team updates along the way.

The browser demonstration adapts selected C# mechanics to JavaScript using simple shapes. The original PainterEngine team game remains private.

# MS Pain — Gameplay Contributions
**Brian Tam · C# gameplay scripting · University team project**

Moving platforms, swap resources and gameplay-testing shortcuts.

**[Try the browser demo](https://light1088.github.io/ms-pain-contributions/)** — watch the platforms, move onto the pickup and collect swaps.

## How my work developed
I started with the **swap-item feature**, then committed a **bug fix**. Next came **rat AI**, followed by **patrol updates and testing**. I later added **vertical moving platforms** and a **cheat-code script**, merging team updates into my Brian branch along the way.

## Browser demonstration
A standalone JavaScript adaptation now demonstrates **platform movement**, **contact-gated swap replenishment** and a **refill shortcut**, based on selected C# scripts. The full PainterEngine game remains private.

The live demo runs in a browser without installation.
